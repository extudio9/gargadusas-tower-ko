# 갈가두사 타워 한글 패치

Windows Steam판 **2.0.0-beta.5304**용 비공식 한국어 패치입니다. 현재 설치 테스트용이며 일부 메뉴와 소식에 영어가 남아 있습니다.

## 다운로드

[버전별 패치 다운로드](https://github.com/extudio9/gargadusas-tower-ko/releases)

Assets에서 `GargadusasTower_KO_beta5304_install-test.zip`을 받으세요. 자동 생성되는 Source code ZIP은 설치 파일이 아닙니다.

## 설치

1. 게임을 종료하고 다운로드한 ZIP을 모두 압축 해제합니다.
2. `한글패치.exe`를 실행하고 게임 설치 폴더를 선택합니다.
3. **한글 패치 적용**을 누릅니다. 원본은 자동 백업됩니다.
4. 완료 후 도구를 닫고 게임을 실행해 한국어를 선택합니다.

지원 원본과 일치하지 않으면 적용하지 않습니다. 디스크 여유 공간 2.5GB 이상이 필요합니다. Python 별도 설치는 필요 없습니다.

## 복원

게임 종료 후 도구의 **원본 복원**을 누르세요. 백업은 `resources/app.asar.ko-original-beta5304`에 보관됩니다.

기존에 다른 방법으로 한글 패치를 설치했다면 **기존 원본 백업 지정**에서 beta.5304의 원본 파일을 선택한 뒤 복원할 수 있습니다.

## 구성 및 검증

이미지·음악·폰트 데이터는 설치된 원본에서 읽습니다. 배포 파일에는 적용 도구와 번역·변경 데이터가 들어 있습니다. 게임 실행 중 번역 프로그램을 켜 둘 필요가 없습니다.

설치·복원, 중복 적용 감지, 미지원 원본 차단, 손상 데이터 사용 시 원본 보존을 검사했습니다. 설치 테스트 빌드는 코드 서명이 없으며, 완전 한글화나 모든 게임 화면의 검증을 의미하지 않습니다.

적용 도구 소스는 `installer.py`입니다. Python 3.11 / PyInstaller 6.21.0에서 `python -m PyInstaller --onefile --windowed --name 한글패치 installer.py`로 빌드했습니다. 패치 데이터는 실행 파일과 같은 폴더에 `patch-data.zip`으로 둡니다.

게임의 권리는 원저작권자에게 있습니다. 오류 제보에는 게임 버전과 문제 화면을 남겨 주세요.
